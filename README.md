# Chest Sorter (Fabric 1.16.5)

Клиентский мод: в сундуках, бочках, шалкерах, воронках, раздатчиках и в инвентаре появляется кнопка **S**.
Нажимаешь — одинаковые предметы объединяются в стаки, а всё содержимое сортируется.

- **S справа вверху сундука** — сортирует сам сундук.
- **S в окне инвентаря (E)** — сортирует ваш инвентарь.

Мод работает через обычные клики по слотам, поэтому подходит и для одиночной игры, и для серверов
(ставить на сервер ничего не нужно — только на клиент).
